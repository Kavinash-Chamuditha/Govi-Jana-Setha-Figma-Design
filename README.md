# 🌾 Govi Jana Setha – Mobile App UI/UX Design

## 📌 Overview
Govi Jana Setha is a **mobile application design prototype** created to support farmers in Sri Lanka.  
This project focuses on designing a user-friendly interface that provides agricultural, environmental, and healthcare information in local languages.

The goal is to improve accessibility and usability for farmers, especially those with low digital literacy.

---

## 🎯 Project Type
📱 UI/UX Design Project (Prototype Only)  
🎨 Designed using Figma  
🚫 No backend / no implementation (design concept only)

---

## 👥 Target Users
- Farmers (small-scale & traditional)  
- Commercial farmers  
- Agricultural officers  
- Kidney patients in rural areas  

---

## 🚀 Key Features (Designed)

### 🌦️ Weather Forecast
- Displays real-time weather updates  
- Helps farmers plan activities  

### 🐘 Wild Elephant Alerts
- Alerts about wild animal movements  
- Quick reporting interface  

### 🌱 Crop Damage Reporting
- Form to submit damage details  
- Upload images/videos  

### 💰 Fertilizer Subsidy Information
- View subsidy details  
- Enter bank details (UI only)  

### 🏥 Kidney Clinic Information
- View clinic schedules  
- Register for appointments (UI concept)  

### 📝 Complaint System
- Submit complaints to government departments  
- Supports text, audio, and video input  

---

## 🎤 Accessibility Features
- Voice typing (speech-to-text UI)  
- Audio support (text-to-speech concept)  
- Large buttons for easy interaction  
- Sinhala language interface  

---

## 🎨 UI/UX Highlights
- Simple and clean layout  
- Color-coded features for easy navigation  
- Designed for low-tech users  
- Focus on accessibility and clarity
